# 论文要求 - 按需读取索引

毕业设计论文格式要求已拆分为以下小文件，**按需读取**以节省 token：

| 文件 | 内容 | 何时读取 |
|------|------|----------|
| [论文要求-页面设置.md](./论文要求-页面设置.md) | 页边距、装订线、页眉 | 做页面/版心设置时 |
| [论文要求-字体与字号.md](./论文要求-字体与字号.md) | 封面、摘要、目录、正文标题与内容、图表字体 | 设置字体、字号、样式时 |
| [论文要求-段落与排版.md](./论文要求-段落与排版.md) | 行距、缩进、段前段后、标点、参考文献、表格/图/列表规则 | 做段落、表格、插图、列表排版时 |
| [论文要求-其他要求.md](./论文要求-其他要求.md) | 关键词数量、用例与模块数量、参考文献格式、图表编号 | 写摘要/图表编号时 |

**用法**：只 @ 或打开当前任务相关的文件，无需一次加载全部要求。
