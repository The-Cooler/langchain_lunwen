# 3. 段落与排版要求 (Paragraph & Layout)

## 3.1 通用段落设置
- **行距**：固定值 23 磅 (图表标题行距为固定值 18 磅)。
- **对齐方式**：两端对齐。
- **缩进**：
  - 正文段落：首行缩进 2 个字符。
  - 目录二级标题：左缩进 2 字符；三级标题：左缩进 4 字符。
  - 所有标题写完，都要换行。
- **段前/段后**：
  - 正文：段前段后 0 行。
  - 章标题：段前 0.5 行，段后 1.5 行。
  - 节/小节标题：段前 0.5 行，段后 0.5 行。
  - 摘要标题：段前 0.5 行，段后 1.5 行。
  - 每个章节题目下都没有分割线，每个章节的最后都要有一个分页符。
  - 图表标题：表标题段前 5 磅，段后 0 磅；图标题段前 0 磅，段后 5 磅。

## 3.2 特殊排版规则
- **标点符号**：
  - 不允许标点出现在行首 (勾选“按中文版式控制首位字符”)。
  - 不允许标点溢出边界 (取消勾选“允许标点溢出边界”)。
  - 字间距设为“标准”。
  - 不允许使用软回车
- **表格**：
  - 三线表 (上下底粗实线 1.5 磅，中间细实线 0.5 磅，无左右边线)。
  - 宽度 100%。
  - 表头居中，其他内容左对齐。
  - 表格标题置于表格上方。
  - 标题格式：表序 + 半角空格 + 表名。
  - 表序按章节编号，如：表1-1、表1-2。居中，五号。
  - 表格标题样式：表格标题。
  - 字体：中文宋体五号，英文 Times New Roman 五号。
  - 段落格式：居中，段前5磅，段后0磅，行距固定值18磅。
  - 表名不允许使用标点符号。
  - 当出现“多行多列结构化数据”（如系统功能列表、用例列表、测试用例、数据库字段说明、模块对比分析等）时，**必须**调用工具 write_table_to_docx(headers, rows, caption) 写入三线表，**禁止**用 write_section_to_docx 把“表x-x 表名”当标题、把表格内容当正文写入；禁止在正文中用 | 或纯文本行表示表格。
  - 表格内容通过 write_table_to_docx 的三个参数传入：表头列表、行数据列表、表标题字符串；系统会按三线表样式自动渲染。
- **图片**：
  - 标题置于图下方。
  - 标题格式：图序 + 半角空格 + 图名。
  - 图序按章节编号，如：图1-1、图1-2。
  - 图片标题样式：图标题。
  - 字体：中文宋体五号，英文 Times New Roman 五号。
  - 段落格式：居中，段前0磅，段后5磅，行距固定值18磅。
  - 图名不允许使用标点符号。
- **列表序号**：
  - 第一级分项：(1), (2) (半角括号)。
  - 第二级分项：①, ②。
