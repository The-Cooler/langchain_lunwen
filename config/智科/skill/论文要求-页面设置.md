# 论文要求 - 页面设置（哈信息教发〔2022〕67 号）

- **纸张**：A4（297mm×210mm），**单面**打印。
- **页边距**：上、下、左、右均为 **2.5 cm**；**装订线**在左侧 **0.5 cm**。
- **页眉**：文字为「**哈尔滨信息工程学院毕业设计（论文）**」，**宋体五号**，**居中**；页眉距顶端 **1.5 cm**。
- **页脚**：距底端 **1 cm**。
- **页码**：从**第 1 章**起用阿拉伯数字（1，2，3…）连续编排；**此前部分**（封面、摘要、目录等）用大写罗马数字（Ⅰ，Ⅱ，Ⅲ…）单独编排。页码在页面底端，**五号 Times New Roman**，**居中**。
